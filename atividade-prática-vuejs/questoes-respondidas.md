# Questões respondidas

1. `data()` serve para definir os dados reativos de um componente ou aplicação no Vue.js.
2. Quando utilizamos `{{ nome }}`, estamos fazendo a interpolação dos dados no template, permitindo exibir na interface o valor de uma variável ou expressão.
3. `v-model` é uma diretiva que conecta um elemento de formulário ao estado da aplicação. É através dela que os dados informados pelo usuário são atualizados e também permite que o estado seja refletido no elemento.
4. `@click` possui como função escutar o evento de clique de um elemento e executar uma ação quando o usuário clicar nele.
5. `v-if` e `v-for` são ambas diretivas do Vue.js. A diferença é que a primeira está ligada à lógica condicional, enquanto a segunda é usada para iterar sobre uma lista de dados ou elementos e renderizá-los repetidamente, sem precisar escrever o mesmo código várias vezes.
6. Quando é dito que o Vue é reativo, quer dizer que, quando um dado reativo é alterado, o Vue identifica essa alteração e atualiza automaticamente a interface que depende desse dado.
7. O .mount("#app") serve para montar a aplicação do Vue no elemento HTML que tiver id="app". É através desse elemento que o Vue consegue controlar e atualizar a interface da aplicação.
